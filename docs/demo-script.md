# Five-minute demo

1. Start with `python main.py --doctor`, then launch in sprite mode with network disconnected to prove local rendering.
2. Trigger greeting, text chat, listening/ASR, thinking, talking, comfort, happy, angry, drag, roam, and night/sleep states.
3. Open Settings to show renderer, perception, screenshot, quiet-hours, autostart, and sensitive-app controls.
4. Open Memory Management; add a harmless preference, edit/delete it, then show that a password-like item is rejected.
5. Restart in Live2D mode, repeat the same semantic actions, and open the parameter debugger.
6. Explain that `.moc3` supports runtime parameter control but not source-level skeleton re-rigging; use the evaluation protocol to select the final renderer.
